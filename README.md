# موقع سكاي إن للسفر والسياحة

موقع ثابت من ست صفحات، باللغة العربية ومن اليمين لليسار. ما يحتاج سيرفر ولا قاعدة بيانات.

| الصفحة | الملف |
|---|---|
| الرئيسية | `index.html` |
| من نحن | `about.html` |
| خدماتنا | `services.html` |
| فروعنا | `locations.html` |
| الوجهات | `places.html` |
| الدعم | `support.html` |

## 1) بيانات التواصل — ملف واحد فقط
عدّل `assets/config.js`: رقم الواتساب، الهاتف، خط الطوارئ، البريد، رقم الترخيص، وروابط السوشال.
كل الصفحات تتحدث تلقائياً.

## 2) الصور
ضع صورك في `assets/images/` بهذه الأسماء بالضبط (JPG):

- `about.jpg` — صفحة من نحن (مقاس مقترح 1000×1250)
- `holiday.jpg` و `honeymoon.jpg` و `family.jpg` — صفحة الخدمات (1200×900)
- الوجهات (900×1200): `istanbul.jpg` `paris.jpg` `zurich.jpg` `baku.jpg` `tbilisi.jpg` `kuala-lumpur.jpg` `phuket.jpg` `maldives.jpg` `bali.jpg`

إذا ما وُجدت الصورة، تظهر خلفية ملونة بدلها.

## 3) محتوى تجريبي لازم تستبدله
- **الأرقام** في صفحة «من نحن» (10+ سنوات، 25,000+ مسافر، 60+ وجهة، 98%) — غيّر قيمة `data-count` والنص معاً.
- **أسعار الوجهات وعدد الليالي** في `places.html`: في البطاقات، وفي بيانات النافذة المنبثقة (JSON في آخر الصفحة).
- **الفروع** (الرياض، جدة، مكة المكرمة): العناوين وقيمة `data-map` المستخدمة في الخريطة.
- **أوقات العمل** في `locations.html` (قيم `data-open` و `data-close` بنظام 24 ساعة)، وفي صفحة الدعم.
- **إجابات الأسئلة الشائعة**، خصوصاً طرق الدفع.

## 4) النماذج
نموذج «عرض السعر» ونموذج «التواصل» يفتحان واتساب برسالة جاهزة.
لاستقبال الرسائل على البريد بدلاً من ذلك: أضف `data-endpoint="https://formspree.io/f/XXXX"` إلى `<form id="contact-form">`.

## 5) تعديل التصميم
التنسيق مبني بـ Tailwind CSS v3 ومُجمَّع مسبقاً في `assets/skyin.css`.
إذا أضفت كلاسات Tailwind جديدة، أعد البناء من داخل المجلد:

```bash
npx tailwindcss@3 -c src/tailwind.config.js -i src/input.css -o assets/skyin.css --minify
```

## 6) النشر
ارفع المجلد كما هو على GitHub Pages أو Netlify أو أي استضافة. الصفحة الرئيسية هي `index.html`.
