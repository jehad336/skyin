# سكاي إن للسفر والسياحة — الموقع والمنصة

موقع عربي (من اليمين لليسار) مع منصة كاملة:

- **حسابات للعملاء**: تسجيل ودخول، وصفحة «حسابي» فيها الحجوزات وطلبات الأسعار والبيانات الشخصية.
- **حجز ودفع أونلاين**: يختار العميل الوجهة والتاريخ وعدد المسافرين، ثم يدفع عبر **ميسّر** (مدى، فيزا، ماستركارد، Apple Pay).
- **طلبات عروض الأسعار ورسائل التواصل** تُحفظ في قاعدة البيانات. وإذا كان السيرفر غير متاح، يفتح واتساب كبديل.
- **لوحة تحكم للإدارة** (`/admin.html`): الإحصائيات، والحجوزات وتغيير حالاتها، وإصدار «حجز مخصص + رابط دفع» لأي عميل (مثلاً كرد على طلب عرض سعر)، والعملاء، والمدفوعات، والرسائل، وإدارة الوجهات والأسعار.

## التقنيات
| الجزء | التقنية |
|---|---|
| الواجهة | HTML + Tailwind CSS v3 + JavaScript بدون مكتبات (`public/`) |
| الباك اند | Node.js 22+ و Express 5 (`server/`) |
| قاعدة البيانات | PostgreSQL 16+ (`server/migrations/`) |
| الدفع | ميسّر (فواتير مستضافة)، مع بوابة تجريبية محلية للتطوير |

## التشغيل محلياً
```bash
npm install
cp .env.example .env          # أول مرة فقط
npm run db:local              # قاعدة بيانات محلية بدون Docker (اتركها شغالة في نافذة)
#   أو: npm run db:up         # إذا عندك Docker Desktop
npm run create-admin -- you@example.com "اسمك"
npm run dev                   # http://localhost:3000
```
عند التشغيل تُنشأ الجداول وتُضاف الوجهات من `data/destinations.json` تلقائياً.

في وضع التطوير (`PAYMENT_PROVIDER=mock`) يفتح زر الدفع **بوابة تجريبية** فيها زرّان: «دفع ناجح» و«دفع مرفوض». لا يُخصم أي مبلغ.

## تفعيل الدفع الحقيقي عبر ميسّر
1. أنشئ حساب تاجر في moyasar.com، ثم انسخ **المفتاح السري التجريبي** (`sk_test_…`).
2. في `.env`:
   ```
   PAYMENT_PROVIDER=moyasar
   MOYASAR_SECRET_KEY=sk_test_…
   PAYMENT_WEBHOOK_KEY=<نص عشوائي طويل>
   APP_URL=https://your-domain.com
   ```
3. جرّب الدفع بالبطاقات التجريبية الموجودة في توثيق ميسّر. بعد ذلك بدّل إلى `sk_live_…`.

السيرفر لا يعتمد على الرابط الذي يرجع به العميل، ولا على الإشعار الذي يرسله ميسّر. في كل مرة يسأل API ميسّر مباشرة بالمفتاح السري، ويطابق المبلغ والعملة قبل أن يعتمد الحجز مدفوعاً.

## تعديل المحتوى والتصميم
- **بيانات التواصل** (واتساب، الهاتف، البريد، الترخيص، السوشال): `public/assets/config.js`.
- **الصفحات** تُولَّد من `_build/tpl/` و `_build/build.py`. لا تعدّل ملفات `public/*.html` مباشرة. بعد أي تعديل شغّل:
  ```bash
  npm run build
  ```
- **الوجهات والأسعار**: من لوحة التحكم ← الوجهات. يُقرأ الملف `data/destinations.json` فقط عند أول تشغيل، أو عند إضافة وجهة جديدة.
- **صور الوجهات**: صور مجانية من Unsplash (رخصتها تسمح بالاستخدام التجاري بدون ذكر المصدر). تقدر تغيّر صورة أي وجهة من لوحة التحكم ← الوجهات ← «رابط الصورة».
- **باقي الصور** (من نحن، والخدمات): ضعها في `public/assets/images/` بالأسماء الموجودة في `README.txt` داخل المجلد.

## النشر (الإنتاج)
يحتاج الموقع خدمة تشغّل Node.js ومعها قاعدة PostgreSQL. صفحات GitHub ما تكفي.
- عرّف المتغيرات: `NODE_ENV=production` و `APP_URL=https://…` و `DATABASE_URL` و `PAYMENT_PROVIDER=moyasar` و `MOYASAR_SECRET_KEY` و `PAYMENT_WEBHOOK_KEY`.
- أمر التشغيل `npm start`. يرفض السيرفر العمل في الإنتاج إذا كانت بوابة الدفع تجريبية أو كان الرابط بدون https.
- فحص الصحة: `GET /healthz`.
